# React Tic-Tac-Toe Tutorial

I followed the React tutorial to build a Tic-Tac-Toe game using React and Vite

## How to Run

1. Make sure Node.js and npm are installed.
2. Open a terminal in the hw3/react folder
3. Install the dependencies:
   npm install
4. Start the application:
   npm run dev
5. Open the localhost URL shown in the terminal (usually `http://localhost:5173/`).

React Tic-Tac-Toe Tutorial: https://react.dev/learn/tutorial-tic-tac-toe
