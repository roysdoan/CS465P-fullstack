# Socket.IO Chat Tutorial

I followed the Socket.IO tutorial to create a simple real-time chat application using Express and Socket.IO

## How to Run

1. Open a terminal in the hw3/socketio folder
2. Install the dependencies:
   npm install
3. Start the application:
   node index.js
4. Open the localhost URL shown in the terminal (usually `http://localhost:3000/`).
5. Open another tab to sending message between tabs

## Tutorial

React Socket Chat Tutorial: https://socket.io/get-started/chat
